This directory contains files generated while working to select a complexes that contain the same protein but different ligands than those in the gold set.  This is a second attempt with emphasis being placed on a broad range of affinities, processable by H++, no change in protonation state on ligand binding, and identical protein sequence to gold-set homologous complex.

2h4g and 2h4k (2hb1 homologs) are good prospects.  Not as much breadth in affinty as I would like.

3b65-3b68 (3b5r homologs) are good prosepects except the affinity range is quite narrow.

3g set (3gr2) are good but range is quite narrow.

3u set (3uo4) are good but range narrow.

5fn set (5fnr) looks great.  Good range of affinities.  All reported in the same paper.
